Get started

Before you begin, install and sign in to the Codex CLI. Use the operating-system and terminal requirements in the full README for your installed version.

  1. Install the bridge

    Run these commands in your local terminal. The setup wizard connects your bot and prepares the bridge service.

    For macOS, Linux, or WSL, keep Codex running in the first terminal as shown below. Run the installation and setup commands in a second terminal. Native Windows uses a different mode; follow the README.

    tmux -L codex new -s codex
codex
    pipx install codex-telegram-bridge
codex-telegram-bridge setup
codex-telegram-bridge doctor

  2. Connect your private bot

    Open the official @BotFather, send /newbot, and create your bot. Enter its token only in the local setup wizard or private configuration file. Send /start to your new bot when the setup instructions ask you to.

  3. Send your first request

    Start with a small request, such as asking the AI to describe the current project. Check the connected terminal and the reply in Telegram. Your CLI permissions and confirmation rules still apply.

Languages

This website

Choose English or 한국어 at the top of the page. All guide text changes immediately, and this browser remembers your choice. A link with ?lang=ko opens the Korean guide directly.

Telegram messages and buttons

In bridge versions that support interface languages, send /language ko or /language en to your own bot. Send /language to check the selection. If the command is unavailable, check your installed release before using it.

AI responses and your account

Website and bridge language choices are separate. Neither setting translates your prompts, AI responses, code, or question options, or changes your model or account. Ask the AI directly if you want an answer in a different language.

Troubleshooting

No reply in Telegram?

Check that the CLI is signed in, the bridge is running, and the configured chat ID belongs to your private conversation with the bot. Use the diagnostics in the README before changing the connection.

Language does not stay selected?

Private browsing or blocked browser storage may prevent the website from saving your choice. The language menu still works for the current page; use ?lang=ko or ?lang=en in a shared link.

Need version-specific instructions?

The README and release notes describe the supported commands and platforms for each version. This guide does not upgrade or restart an installed bridge.

시작하기

먼저 Codex CLI를 설치하고 로그인하세요. 운영체제와 터미널 준비 사항은 설치한 버전의 전체 README를 확인하세요.

  1. 브릿지 설치

    컴퓨터의 로컬 터미널에서 실행하세요. 설정 도구가 봇을 연결하고 브릿지 서비스를 준비합니다.

    macOS·Linux·WSL에서는 첫 번째 터미널에서 아래와 같이 Codex를 켜 둡니다. 설치·설정 명령은 두 번째 터미널에서 실행하세요. 기본 Windows 터미널은 별도 모드를 사용하므로 README를 따르세요.

    tmux -L codex new -s codex
codex
    pipx install codex-telegram-bridge
codex-telegram-bridge setup
codex-telegram-bridge doctor

  2. 본인 전용 봇 연결

    공식 @BotFather에 /newbot을 보내 봇을 만드세요. 받은 토큰은 로컬 설정 도구나 비공개 설정 파일에만 입력합니다. 설정 안내에서 요청할 때 새 봇에 /start를 보내세요.

  3. 첫 요청 보내기

    현재 프로젝트를 설명해 달라는 작은 요청부터 보내세요. 연결된 터미널과 텔레그램 답변을 확인합니다. CLI의 기존 권한과 승인 규칙이 그대로 적용됩니다.

언어 설정

이 웹 설명서

페이지 위에서 한국어 또는 English를 선택하면 설명서 전체가 즉시 바뀌고, 이 브라우저에 선택이 저장됩니다. 주소에 ?lang=ko를 붙인 링크는 한국어 안내로 열립니다.

텔레그램 안내와 버튼

언어 설정을 지원하는 브릿지 버전에서는 본인 봇에 /language ko 또는 /language en을 보내세요. /language로 현재 선택을 확인합니다. 명령이 없다면 사용 중인 릴리스의 지원 여부를 먼저 확인하세요.

AI 답변과 계정

웹 설명서와 브릿지 언어는 각각 선택합니다. 요청, AI 답변, 코드, 질문 선택지를 번역하거나 모델·계정을 바꾸지는 않습니다. 답변 언어는 AI에게 직접 요청하세요.

문제 해결

텔레그램에 답이 오지 않나요?

CLI 로그인, 브릿지 실행 상태, 본인 봇 대화의 채팅 ID 설정을 확인하세요. 연결 설정을 바꾸기 전에 README의 진단 절차를 따르세요.

선택한 언어가 저장되지 않나요?

비공개 브라우징이나 브라우저 저장소 차단 상태에서는 웹 언어가 저장되지 않을 수 있습니다. 현재 페이지의 언어 선택은 사용할 수 있고, 공유 링크에는 ?lang=ko 또는 ?lang=en을 붙이면 됩니다.

설치 버전의 상세 안내가 필요한가요?

버전별 지원 명령과 운영체제는 README와 릴리스 노트에서 확인하세요. 이 설명서는 설치된 브릿지를 업데이트하거나 재시작하지 않습니다.
