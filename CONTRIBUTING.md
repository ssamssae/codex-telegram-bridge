# Contributing

This repository is MIT. You may fork it, change it, and send the change back.

## Pull requests

1. Fork this repository.
2. Keep the change small and on one branch.
3. Run the tests that already live in this repository.
4. Open a pull request against this public repository.

## Do not include

- Bot tokens, chat ids, passwords, or personal file paths
- Private hostnames or one-machine operator setup

## Issues

Bugs and ideas belong in Issues. Say what you ran and what you expected.

This public copy is a sanitized export. Maintainers may take time to reply. Keep the MIT notice in copies you publish.
